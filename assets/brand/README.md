# VibeProxy brand banner

`vibeproxy-banner.png` is the 2000 × 750 PNG supplied by the user as
“VibeProxy Orbital Developer Banner.png”. It is used unchanged at the top of the
repository README.

The banner combines the VibeProxy wordmark and tagline with a silver orbital ring,
four-point sparkle, black background, and restrained blue accent. Product screenshot
samples are kept separately in `assets/screenshots/`.

The release packaging script includes this directory so the README image also works
in future downloaded release archives.
